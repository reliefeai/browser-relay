Browser Relay

Connect your Chrome browser to any AI agent.

Detach the debugger from a tab after this many idle seconds so Chrome's "started debugging this browser" bar disappears. It re-attaches automatically on the next command. Set 0 to disable (bar always shown). Trade-off: CDP events are not received while a tab is idle-detached.

How it works:
1. Install the relay server: npm install -g @linsoai/browser-relay
2. Check it: browser-relay status (auto-starts on login too)
3. Enter the port above (default 18795) and save
4. The extension auto-connects and attaches all open tabs
