01Local Relay

Bridges your Chrome tabs to the local Browser Relay daemon on 127.0.0.1 for direct, on-device control. Remote Relay below runs on its own and does not need this.

Off

Allow agents to read and operate these Chrome tabs?

Agents connected to the local daemon can act with the same logged-in browser session you use.

  • Read tab URLs and titles, page text, DOM/accessibility data, selection, screenshots, console output, network metadata, and values explicitly evaluated in the page (which can include non-HttpOnly cookies).
  • Click, type, submit forms, scroll, navigate, open, activate, and close tabs.
  • Chrome shows its debugger notice while a tab is attached; idle auto-detach reduces how long it stays visible.
  • Local mode sends commands and results only between this extension and the daemon on this computer. Remote Relay is a separate opt-in below.
Chrome downloads (optional)

Lets agents start downloads and read download history. Keep it off if you do not use download commands.

02Remote Relay

Control this browser from anywhere through the hub — no open ports, no exposed server. Mints a secret Device ID that works until you switch off. Prefer your own hub? Deploy to Cloudflare →

Off

Send browser commands and results through this Remote Hub?

Remote Relay makes this logged-in browser controllable by anyone who has the secret Device ID.

  • The selected Hub can relay tab URLs/titles, page text and DOM/accessibility data, screenshots, selection, console output, and network metadata that may contain sensitive URLs or headers.
  • Remote agents can click, type, submit forms, scroll, navigate, and manage tabs using your existing login state.
  • The extension does not request Chrome's cookies permission, but explicit page evaluation can read values available to page JavaScript, including non-HttpOnly cookies. Remote agents can also act as you on signed-in pages.
  • The Device ID is a password-like capability. Browser Relay stores it in this extension until you switch Remote Relay off.

Read the Privacy Policy before enabling.

This invalidates the current Device ID immediately — anything using the old one must switch to the new ID.
Quick start
  1. Install the CLI — npm i -g @linsoai/browser-relay
  2. Check it — browser-relay status (auto-starts on login)
  3. Save the Local Relay settings above
  4. Flip Remote Relay on, copy the command, run it from anywhere
