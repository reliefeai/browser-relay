# Browser Relay Hub on Cloudflare

This directory contains the Cloudflare Worker + Durable Object implementation of the Browser Relay Hub.

## Deploy

```bash
npm run hub:deploy
```

The default `wrangler.toml` deploys the worker as `browser-relay-hub` and attaches the custom domain:

```text
https://relay.linso.ai
```

One-click deploy button draft:

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/reliefeai/browser-relay/tree/main/hub)

## Local smoke checks

```bash
curl https://relay.linso.ai/v1/health
```

Expected shape:

```json
{ "ok": true, "service": "browser-relay-hub" }
```

## Protocol endpoints

- `GET /v1/device/connect?routeId=...` — device outbound WebSocket from the local relay daemon.
- `POST /v1/rpc` — remote CLI/MCP RPC entrypoint.
- `GET /v1/status/:routeId` — authenticated device online status.

The `remote-device-id` generated by the browser extension is a capability secret. The hub stores only a SHA-256 hash of the secret inside the device Durable Object.
